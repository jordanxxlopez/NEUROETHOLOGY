Compressed distribution edition of the 20-video Lecture 100. Only the five largest embedded MP4s are recompressed using H.264, CRF21, medium preset, at their existing native resolution and frame rate. Audio packets are copied without re-encoding. The other fifteen videos remain byte-identical. All slide XML, scientific figures, source-frame posters, layout, fonts, colors, title, date and lecture text remain byte-identical; only the five relevant compatibility-note lines are updated to describe this distribution copy accurately.

Compression is lossy, and decoded frames cannot be claimed pixel-identical. Validation checks native dimensions, frame counts, frame rates, duration, audio payload hashes and full decoding, followed by sampled SSIM and visual comparisons. Desktop PowerPoint playback is untested. The existing 20-video PDF remains an accurate static preview because its figures and recording posters are unchanged. The original full-size deck and media are retained.

Run compress_media.py, validate_compression.py and package_compressed.py from the repository root. See compression.json, validation.json and artifact.json for exact settings and source-to-distribution hashes.

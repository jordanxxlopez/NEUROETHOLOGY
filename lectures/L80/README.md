# Lecture 80

Songbirds I: Artificial song memories, optogenetic tutoring, and neural mechanisms of vocal imitation

Date TBD

Build with the repository environment:

```bash
python lectures/L80/write_spec.py
python tools/build_lecture.py lectures/L80/lecture.json
python lectures/L80/embed_video.py
python tools/check_lecture.py lectures/L80/Neuroethology_Lecture80_FA2026.pptx --lecture 80
```

The four supplied primary PDFs belong in `papers/` and are intentionally not committed. Original PDF crop coordinates are in `crops.json`. MP4 files are codec conversions of the publisher MOV recordings with their original timing and audio retained. Provenance is in `media_sources.json`. The title photograph is an original frame at 17 seconds of Roberts et al. (2012), Supplementary Video 1.

Click the videos during PowerPoint Slide Show on slides 14, 27, 28 and 29. Browser/PDF exports are static; original frames and article figures remain visible when videos are omitted.
